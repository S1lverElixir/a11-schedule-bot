# Спецификация личного бота расписания группы А-11 (БТЭУ)

Артефакты: SPEC.md (этот файл) и schedule_data.py (единственный источник данных).
Код бота в эту спецификацию не входит.

## 1. Назначение и рамки

1. Бот для одного человека. Токен и MY_TELEGRAM_ID берутся из переменных окружения.
2. Сообщения от MY_TELEGRAM_ID обрабатываются; от всех остальных — полное молчание: без ответа, без реакции.
3. Только long polling. Без webhook, веб-сервера, базы данных и файлов состояния. Один процесс.
4. Часовой пояс — фиксированный UTC+3 (Минск), одной константой `timezone(timedelta(hours=3))`. pytz/zoneinfo не используются, чтобы не зависеть от tz-базы хостинга.
5. Источник правды по расписанию — schedule_data.py: `SCHEDULE`, `week_mark`, `SEMESTER_START`, `SEMESTER_END`, `BELLS`. Данные в коде бота не дублируются.

## 2. Команды и клавиатура

6. Единственная команда — /start: однострочное приветствие + reply-клавиатура. Других команд нет, никакого текста /start не возвращает, кроме одной строки.
7. Reply-клавиатура, два ряда: «Сегодня» «Завтра» «Сейчас» «Неделя» / «Звонки» «Выбрать день». Тексты кнопок без эмодзи.
8. Любой другой текст от владельца игнорируется молча (без сообщений об ошибке).

## 3. Просмотр одного дня

Кнопки «Сегодня», «Завтра» и тап по дате в календаре отправляют расписание одного дня.

9. Шаблон сообщения:

```
Пятница, 23.10.2026 · сегодня
Неделя под чертой

1-я пара 09:00–10:35
Экономическая теория, ауд. 2-11
ст.пр. Барабанова И.В.

2-я пара 10:50–12:25
...
```

10. Первая строка: день недели с заглавной буквы и дата DD.MM.YYYY. Суффикс « · сегодня» добавляется только при показе по кнопке «Сегодня», « · завтра» — только по кнопке «Завтра»; даты, выбранные в календаре, выводятся без суффикса — даже если это сегодня или завтра.
11. Вторая строка: «Неделя над чертой» либо «Неделя под чертой».
12. Блок пары — три строки, разделённые пустой строкой от соседних блоков:
    - «N-я пара HH:MM–HH:MM»;
    - «Предмет» или «Предмет, ауд. комнаты» (аудитории — строка из данных как есть, без аудитории запятая не пишется);
    - преподаватели через запятую, одной строкой.
13. День без пар: две строки заголовка, пустая строка, строка «пар нет».
14. Статус — последняя строка сообщения (после пустой строки). Выводится только для сегодняшнего дня и вычисляется в момент отправки по UTC+3:
    - до начала 1-й пары дня: «до первой пары N мин»;
    - идёт одна из пар дня: «идёт N-я пара, до конца M мин»;
    - между парами дня: «перемена, до N-й пары M мин», где N — номер следующей пары этого дня (любой промежуток между соседними парами дня — «перемена», независимо от длительности);
    - после конца последней пары дня: «занятия окончены»;
    - пар нет: «сегодня пар нет» (заменяет собой строку «пар нет» из п. 13).
    N и M — целые минуты. Момент окончания пары — уже перемена/окончание; момент начала — уже пара.
15. Тип занятия (лекция/практика) нигде не выводится; этих данных нет в schedule_data.py.

## 4. Кнопки «Сейчас» и «Неделя»

16. «Сейчас» показывает состояние на момент отправки: шапка «Сейчас HH:MM, День DD.MM» + черта недели; далее — идущая пара (блок пары + «до конца M мин» + строка «далее: N-я пара HH:MM, Предмет»), либо «перемена/до первой пары, M мин» с блоком следующей пары, либо «занятия окончены», либо «сегодня пар нет»; в двух последних случаях добавляется ближайшая пара впереди («завтра: …» или «ближайшие пары: …» в пределах недели).
17. «Неделя» показывает неделю, содержащую сегодня; под сообщением — inline-кнопки «‹»/«›» (предыдущая/следующая неделя с сохранением формата) и «экспорт в календарь».
18. Шаблон недели (пример для реальной под-чёрной недели):

```
Неделя 19.10–25.10 · под чертой

Пн 19.10
1 (09:00) Физическая культура
2 (10:50) Математический анализ, ауд. 1-13
3 (12:55) Компьютерные информационные технологии, ауд. 1-2
4 (14:40) Информационный час, ауд. 3-27
4 пары

Сб 24.10
1 (09:00) Линейная алгебра и аналитическая геометрия, ауд. 1-9
2 (10:50) Линейная алгебра и аналитическая геометрия, ауд. 1-9
2 пары

Вс 25.10
пар нет
```

19. Блок дня: строка «Пн DD.MM», далее одна строка на пару: «N (HH:MM) Предмет» с «, ауд. комнаты» при наличии. Преподаватели в недельном виде не выводятся.
20. Итоговая строка дня: «1 пара», «2 пары», «3 пары», «4 пары», «5 пар» (1 — пара; 2–4 — пары; 5 и больше — пар). День без пар — «пар нет». Блоки дней разделяются пустой строкой.
21. Кнопка «экспорт в календарь» отправляет .ics-файл выбранной недели: событие на каждую пару (предмет — SUMMARY, аудитория — LOCATION, преподаватели — DESCRIPTION), время локальное плавающее, имя вида «raspisanie_26.10-01.11.ics», подпись с чертой недели.

## 5. Кнопка «Звонки»

22. Отправляет таблицу звонков в HTML: заголовок «Расписание звонков» жирным, ниже — моношрифт-блок: на каждую пару две строки — «N-я HH:MM–HH:MM   перерыв N мин» (у последней пары перерыва нет) и отступом «1-й урок · перемена 5 мин · 2-й урок». Данные берутся из структуры `BELLS` в schedule_data.py.

## 6. Кнопка «Выбрать день» (inline-календарь)

23. По нажатию открывается inline-клавиатура: первая строка «‹» «Название месяца год» «›» (например «‹ Октябрь 2026 ›»), вторая — строка заголовков дней недели «Пн Вт Ср Чт Пт Сб Вс» (неактивные кнопки), ниже — сетка дат текущего месяца, недели начинаются с понедельника. Кнопка сегодняшней даты помечается точкой после числа («23·»).
24. «‹» и «›» переключают месяц. Стрелка не выводится, если соседний месяц не пересекается с семестром.
25. Кнопки-даты активны только в пределах SEMESTER_START..SEMESTER_END; дни вне семестра — пустые (неактивные) клетки.
26. Тап по дате отправляет новое сообщение с расписанием этого дня по разделу 3 (без суффикса « · сегодня/завтра»); сообщение с календарём не редактируется и остаётся в чате.

## 7. Недели над/под чертой

27. Чередование по неделям (Пн–Вс). Якорь: неделя с понедельника 21.09.2026 — ПОД чертой. Подтверждение по исходной таблице: все варианты «под чертой» имеют пометки «с 21.09.26 / 24.09.26 / 25.09.26 / 26.09.26», и все эти даты лежат в одной неделе 21–27.09.2026.
28. Расчёт — функцией `week_mark(day)` из schedule_data.py. Даты до якоря экстраполируются тем же правилом (чередование продолжается в обе стороны).
29. Даты вне SEMESTER_START..SEMESTER_END — каникулы: любой день «пар нет». Кнопки «Сегодня»/«Завтра» за пределами семестра тоже дают «пар нет».

## 8. Стиль

30. Сообщения без эмодзи. Форматирование — Telegram HTML (parse_mode="HTML"): в виде дня шапка и строки «N-я пара …» жирным, статусные строки курсивом; «Звонки» — моношрифт-таблица; «Неделя» — обычный текст. Никаких markdown-символов в самом тексте сообщений.
31. Отступы и разделители — строго по шаблонам разделов 3–5; экранирование HTML обязательно (html.escape для предметов, имён, суффиксов).
32. Названия предметов, аудитории и преподаватели выводятся дословно из schedule_data.py, без сокращений и перестановок.

## 9. Надёжность и инфраструктура

33. Деплой: пуш в main ветку репозитория запускает GitHub Actions (deploy.yml), который через API панели fps.ms перезапускает сервер; при старте сервер сам делает git pull (AUTO_UPDATE) и запускает run.py (клон при пустой папке, установка зависимостей офлайн из wheels/).
34. Healthcheck: GitHub Actions ежечасно проверяет, что бот держит polling (пробный getUpdates должен вернуть 409); при сбое бот-уведомление владельцу и попытка рестарта через API панели (healthcheck.yml).
35. Watchdog продления: bot.py раз в час читает срок сервера через API панели и отправляет владельцу напоминание «Add 24 hours», когда до остановки остаётся меньше суток и затем меньше 6 часов (продление защищено reCAPTCHA и не автоматизируется честно).
36. Утренняя сводка: ежедневно в MORNING_SUMMARY_TIME (по умолчанию 07:30 по Минску, задаётся в .env; пустое значение выключает) бот сам присылает раскладку дня: шапка «Доброе утро. День, DD.MM.YYYY» + черта недели, по строке «N (HH:MM) Предмет, ауд.» на пару, итог «N пар(ы)»; в дни без пар — «сегодня пар нет». Сводка не отправляется вне SEMESTER_START..SEMESTER_END и не догоняется, если бот был выключен в окно отправки (90 минут).
