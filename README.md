# Расписание А-11 (БТЭУ)

Личный Telegram-бот расписания учебной группы. Один пользователь — владелец; от всех
остальных полное молчание. Прод — воркер `a11-bot` на Cloudflare Workers
(https://a11-bot.egor-kuzko-04.workers.dev), вебхук с fail-closed секретом.

Возможности: «Сегодня», «Завтра», «Сейчас», «Неделя» с перелистыванием и экспортом
недели в `.ics`, «Звонки», inline-календарь по дням семестра, утренняя сводка в 07:30,
датные замены занятий поверх стабильного расписания. Часовой пояс фиксированный
UTC+3, без библиотек времени и без tz-базы платформы.

## Что где

- **workers/** — весь бот: `src/` — модули (вход `src/index.ts`), `test/` — тесты и
  замороженные фикстуры (`test/fixtures/`), `tools/` — секреты, вебхук, пересъёмка
  эталона видов.
- **workers/src/schedule.ts** — единственный источник данных: расписание, замены,
  звонки, типы занятий, границы семестра, якорь чередования недель.
- **workers/tools/dump_views.ts** — пересъёмка эталона видов; гейт сверяет её вывод
  с фикстурой байт-в-байт, так что тихий дрейф невозможен.
- **tools/check_site.py** — сверка с bteu.by: стабильная таблица, таблица учебных
  недель, начитка и график кураторского часа; найденные замены печатает блоком,
  который человек переносит в данные.
- **SPEC.md** — контракт поведения: форматы сообщений, статусы, правила.
- **AGENTS.md** — правила работы для кодинг-агентов; **.agents/skills/verify-bot/** —
  скилл всесторонней проверки.

## Запуск и проверка

```powershell
cd workers; npm install; npm test          # тесты с паритетом фикстур внутри
cd workers; npm run typecheck              # tsc --noEmit
python -X utf8 .agents/skills/verify-bot/scripts/verify_bot.py --local   # весь локальный гейт
python -X utf8 .agents/skills/verify-bot/scripts/verify_bot.py           # плюс прод: 409, вебхук
python -X utf8 tools/check_site.py         # сверка расписания с сайтом (нужен xlrd)
```

Для `check_site.py` нужен `xlrd` (`python -m pip install xlrd`). Зелёный итог любой
проверки — строка `ИТОГ: FAIL=…`; её приводят в отчёте, а не пересказывают словами.

## Прод

Деплой вручную: `cd workers; npx wrangler deploy` — печатает URL и кроны. Секреты
(`BOT_TOKEN`, `MY_TELEGRAM_ID`, `WEBHOOK_SECRET`) ставит workers/tools/set_secrets.mjs;
сразу после него тот же секрет уходит в set_webhook.mjs, иначе доставки начнут
падать с 401. Пуш в `main` запускает CI: `ci.yml` гоняет локальный гейт,
`healthcheck.yml` дважды в час проверяет живость канала Telegram и свежесть ошибок
доставки вебхука, при сбое будит владельца. Базы данных и файлов состояния нет:
KV хранит только отметку «сводка за сегодня уже ушла».
