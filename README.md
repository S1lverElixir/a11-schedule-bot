# Расписание А-11 (БТЭУ)

Личный Telegram-бот расписания для одного человека: отвечает только владельцу
(MY_TELEGRAM_ID), остальным — молчание. Кнопки: Сегодня, Завтра, Сейчас, Неделя,
Звонки, Выбрать день (inline-календарь в пределах семестра). Есть недельный
экспорт в .ics и утренняя сводка.

- **rust/** — бот: исходники, снимки паритета и служебные скрипты, см. `rust/README.md`.
- **rust/src/schedule.rs** — единственный источник данных: расписание, звонки,
  типы занятий (KIND), границы семестра, якорь чередования недель.
- **SPEC.md** — спецификация (форматы сообщений, статусы, правила).
- **run.py** — вход на хосте: скачивает репозиторий, если его нет, проверяет
  самотестом и запускает Rust-бинарник.
- **AGENTS.md** — правила для кодинг-агентов; **.agents/skills/verify-bot/** —
  скилл всесторонней проверки.

## Запуск локально

```
cp .env.example .env   # вписать BOT_TOKEN (от @BotFather) и MY_TELEGRAM_ID (от @userinfobot)
cargo run --release --manifest-path rust/Cargo.toml
```

Проверка без сети: `python -X utf8 rust/tools/check.py` (сборка, тесты, паритет,
память), полная — `python -X utf8 .agents/skills/verify-bot/scripts/verify_bot.py --local`.

## Прод

fps.ms (бесплатный контейнер, 128 МБ RAM): push в main → GitHub Actions
`.github/workflows/deploy.yml` перезапускает контейнер, тот подтягивает код и
запускает `run.py`. Раз в сутки сервер нужно продлевать кнопкой «Add 24 hours»
в панели — watchdog бота напоминает в Telegram. Ежечасный healthcheck
(`healthcheck.yml`) алертом сообщает, если бот перестал держать polling.

Часовой пояс фиксированный UTC+3, без pytz/zoneinfo.
