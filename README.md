# Расписание А-11 (БТЭУ)

Личный Telegram-бот расписания для одного человека: отвечает только владельцу
(MY_TELEGRAM_ID), остальным — молчание. Кнопки: Сегодня, Завтра, Неделя,
Звонки, Выбрать день (inline-календарь в пределах семестра).

- **bot.py** — бот целиком (aiogram 3.x, только long polling, без БД и веб-сервера)
- **schedule_data.py** — единственный источник данных: расписание, звонки, якорь чередования недель
- **SPEC.md** — спецификация (форматы сообщений, статусы, правила)
- **requirements.txt**, **.env.example**

## Запуск

```
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN (от @BotFather) и MY_TELEGRAM_ID (от @userinfobot)
python bot.py
```

Хостинг с ограничениями (256 МБ RAM достаточно): запуск в `screen`,
перезапуск по cron. Часовой пояс фиксированный UTC+3, без pytz/zoneinfo.
